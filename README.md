# ZOI PLUS GitHub Pages

Version estatica del e-commerce ZOI PLUS para GitHub Pages.

- Carga inventario desde `products.json`.
- Usa rutas relativas para funcionar en `/ZOI_PLUS/`.
- Guarda pedidos y cotizaciones en `localStorage` durante 48 horas cuando no hay backend.
- No reemplaza la version completa con `server.mjs`, n8n y respaldos CSV del servidor.

Para publicar: servir esta carpeta como raiz de GitHub Pages o usar la rama `gh-pages`.
